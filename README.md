# dotfiles

## `fish`

1. Install fish via `sudo pacman -S fish`
2. Copy `fish/` to `~/.config/fish/`

## `hyprland.conf`

1. Ensure hyprland is installed
2. Copy to `~/.config/hypr/hyprland.conf`

## `nvim`

1. Install neovim via instructions on website
2. Move `nvim/` to `~/.config/nvim/`

## `.tmux.conf`

1. Install tmux and `tpm` if don't have already
2. Copy `.tmux.conf` to `~/.tmux.conf`
3. `<prefix> I` (capital I) installs plugins
4. `<prefix> r` reloads tmux settings
