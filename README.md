# dotfiles

Everything here usually requires `conda`.

## `fish`

1. Install the `fish` shell.
2. Copy `fish/` into `~/.config/fish/`.
3. Double-check fish's user paths (in `fish_variables`).

## `tmux`

1. Install `tmux` on whatever system.
2. Copy `.tmux.conf` to `~/.tmux.conf`.

## `nvim`

1. Install `neovim`.
2. Copy `nvim/` into `~/.config/nvim/`.
3. Open Lazy in nvim and ensure all packages are installed.
